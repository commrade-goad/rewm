* rewm: Missing Features Compared to dwm

** Major Gaps

*** Multi-Monitor Support
- No Xinerama support, single monitor only
- Missing: =updategeom()=, =createmon()=, =cleanupmon()=, =dirtomon()=, =recttomon()=
- Missing: =focusmon()=, =sendmon()=, =tagmon()=, =isuniquegeom()=

*** System Tray
- Completely missing XEmbed-based system tray
- Missing: =Systray= struct, =updatesystray()=, =updatesystrayicongeom()=
- Missing: =updatesystrayiconstate()=, =removesystrayicon()=, =getsystraywidth()=
- Missing: XEMBED message handling (=XEMBED_EMBEDDED_NOTIFY=, =XEMBED_FOCUS_IN=, etc.)

*** Xresources Runtime Configuration
- No =load_xresources()=, =reload_xresources()=, =resource_load()=
- No =ResourcePref= struct for typed resource mapping

*** Anti-Aliased Fonts
- Core X fonts only (=XLoadQueryFont=), no Xft/fontconfig
- No font fallback, no font set support

** Missing Event Handlers

|-----------------+-----+---------|

| =MotionNotify=  | Yes | Missing |
| =ResizeRequest= | Yes | Missing |

** Minor Gaps

- No =checkotherwm()= at startup
- No =cleanup()= on exit
- No aspect ratio hints (=PAspect=, =mina=/=maxa=)
- No window centering on spawn
- No =SIGCHLD= handler for zombies
- No =getstate()= for iconic state detection
- No =hintsvalid= optimization (always re-reads size hints)
- No =INTERSECT= macro for monitor overlap calculation
- No =nexttagged()= helper for =attachaside()=
- No =focusin()= handler for focus stealing prevention
- No =MotionNotify= on root for monitor focus follow pointer
- No double-buffered bar rendering
- No locale support (=setlocale()=, =XSupportsLocale()=)
- =grabkeys()= uses =XKeysymToKeycode()= (single keycode) instead of =XGetKeyboardMapping()= (all matching keycodes)
- =scanwindows()= is single-pass, no separate transient pass
- =unmanage()= does not restore =border_width= to =oldbw=
- Transient windows don't inherit parent's monitor/tags
- Bar windows lack =override_redirect=, =ParentRelative= background, and XClassHint
- =sendevent()= is specialized for WM_PROTOCOLS only, not general-purpose

** What rewm Has That dwm Does Not

- Hot-reload via JIT (MOD+Shift+R recompiles without restart)
- =movestack= built-in (MOD+Shift+J/K)
- =setgapsabs= (MOD+Shift+=)
- =togglesticky= (patch in dwm, built-in in rewm)
